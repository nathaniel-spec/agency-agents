# Guest Message Templates

Short, warm, 5th-grade reading level. Only say things that are **true**. Swap
`[brackets]` for real details. The referral offer is always the same:

> **Refer a friend who books and you get $200 — and they get 10% off their
> first stay.**

---

## Guest rating (do this first, so praise stays honest)

Rate each guest 1–5 before writing:

| Factor            | 1–5 |
|-------------------|-----|
| Cleanliness       |     |
| Communication     |     |
| Respected rules   |     |
| Care of the home  |     |
| Would host again? | Y/N |

- **4.5–5.0** → glowing review + strong invite-back + referral
- **3.5–4.4** → warm and honest, lighter invite
- **below 3.5** → polite and brief, skip the strong invite

---

## Template A — Review request (guest hasn't reviewed yet)

> Hi [Name]! It was so nice to host you[ and (partner/family/dog)]. [One true,
> specific line — e.g. "You left the place spotless."]
>
> If you have a minute, a quick review would mean a lot. It helps other guests
> find the place.
>
> And a thank-you: refer a friend who books and you get **$200** — they get
> **10% off** their first stay. Come back any time. 🙏

## Template B — Response to a review they left

> Thank you so much, [Name]! You were a wonderful guest — [2 specific
> compliments, e.g. "so tidy and easy to talk to."] I'd host you again in a
> heartbeat.
>
> Refer a friend who books and you get **$200** — they get **10% off**. The
> door's always open. Come back soon! 🌟

## Template C — Gracious reply to a critical review

> Thank you for the honest feedback, [Name]. I'm sorry [specific thing] fell
> short — I've noted it and I'm fixing it. I appreciate you staying with us and
> wish you safe travels.

## Template D — New-booking welcome / question answer

> Hi [Name]! Thanks for booking — I'm glad to host you. [Answer their question
> using the knowledge base, or: "Great question — [answer]."] Anything you need,
> just message me. See you [dates]! 🏡
