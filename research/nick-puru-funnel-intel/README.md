# Nick Puru (@nicholas.puru): funnel intelligence report

Open **`index.html`** in a browser. It is a self-contained page that loads images from `evidence/`.

Captured 15 Nov 2026 from public sources only. No forms were submitted, no messages sent, nothing purchased, and no login walls were bypassed.

| Path | Contents |
|---|---|
| `index.html` | Full report: summary, funnel map, page-by-page evidence, content/CTA inventory, offers, copy analysis, tech stack, unknowns, recommendations, blueprint |
| `evidence/screenshots/` | Desktop (1366px) and mobile (iPhone 13) full-page captures, WebP |
| `evidence/page-data/` | Per-page JSON: final URL, redirects, links, buttons, forms, iframes, page text, network requests |
| `evidence/form-walks/` | Step-by-step form screenshots plus logs of requests the browser tried to send (all blocked) |
| `evidence/forms/` | Typeform question/logic definitions parsed from the public form pages |
| `evidence/external/` | Instagram reel pages, YouTube tabs, Meta Ad Library, Linktree, Threads, and blocked-access proofs |
| `evidence/tools/` | Playwright capture and form-walk scripts used to collect the evidence |

Every claim in the report is labelled VERIFIED, INFERRED or UNKNOWN.
